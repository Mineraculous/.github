# Mineraculous Organization Tooling (.github)

This repository serves as the central hub for the [Mineraculous](https://github.com/Mineraculous) organization, hosting:

- **Central Renovate Presets** (`renovate.json`) for toolchain and Actions management.
- **Reusable GitHub Actions Workflows** (`.github/workflows/`) for mod dependency updates and README syncing.
- **Shared Gradle Conventions** (`gradle/conventions.gradle`) for Maven repositories, git hooks, and build helpers.
- **Core Scripts** (`scripts/`) for Modrinth and Maven dependency automation.
